BeyondContact

Airflow-assisted manipulation with Piper-L: learning to move and reorient objects through directed airflow and gripper assistance.

Research platform

Airflow physics and two manipulation tasks

A reusable Isaac Lab extension connects batched airflow forces to reinforcement learning environments.

01

Blower extension

Configurable jet physics, surface force and torque integration, target objects and debug visualisation.

02

Gripper-assisted box pushing

Piper-L controls the blower and uses gripper assistance to move a box into a target region.

03

Rectangular reorientation

Move a cuboid toward its target position and orientation with a learned manipulation policy.

Airflow physics

From jet velocity to object motion

The shared extension evaluates a Gaussian free-jet profile and integrates forces and torques across sampled object surfaces.

Batched PyTorch modelSurface samplingForce and torque integrationConfigurable visualisation

Reinforcement learning

Two tasks, one Piper-L platform

Manager-based environments with joint-position and airflow actions, task-specific rewards and PPO training through RSL-RL. Each task includes a Play configuration for evaluation.

GripperAssistBoxPushGripperAssistCuboidOrientation

The rectangular reorientation task retains the CuboidOrientation identifier in the code. Pretrained checkpoints are not included in this release.

Get started

Install the airflow extension, then the RL framework

Use an environment with Isaac Sim 5.1.0, compatible Isaac Lab, Python 3.11, PyTorch and RSL-RL.

python -m pip install -e external_blower/blower/source/blowerpython -m pip install -e blower_arm_rl/source/blower_arm_rlpython blower_arm_rl/scripts/rsl_rl/train.py --task Isaac-Blower-Piper-GripperAssistBoxPush-v0 --headlesspython blower_arm_rl/scripts/rsl_rl/train.py --task Isaac-Blower-Piper-GripperAssistCuboidOrientation-v0 --headless
